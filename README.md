# Python Airline Booking System

## About the Project

This project is a Python-based airline booking and passenger management system that I originally developed at approximately 16 years old during my first year of Level 3 Engineering studies.

The application was designed to simulate different stages of an airline's passenger check-in and booking process, including passenger information, age verification, baggage management, security questions, and destination selection.

The original program grew to approximately 500 lines of Python code. Unfortunately, a significant portion of the original source code was lost, leaving only a partially recovered version.

Rather than abandoning the project, I have decided to restore it as closely as possible to its original design, preserving the programming techniques and features I developed at the time.

## Original Features

### Features Present in the Recovered Code

- Passenger registration, including personal information and date of birth.
- Age verification against the passenger's provided date of birth.
- Additional guardian checks for younger passengers.
- Baggage weight calculations and associated charges.
- Cabin baggage restrictions and additional fees.
- Passenger security questions.
- Destination selection from five international airports.
- A custom navigation system for managing different stages of the application.

### Features Awaiting Restoration

The original application included additional functionality that is no longer present in the recovered source code.

These features included:

- Optional additional seat purchases.
- In-flight food selection.
- Calculations for the total booking cost.
- Further stages of the booking process.

Additional functionality may be recovered as I revisit the original project.
